Lum (Local Universal Machine)

차세대 AI 통합 터미널 에뮬레이터 프로젝트 상세 보고서

1. 프로젝트 개요

Lum은 로컬 AI 모델과 클라우드 AI를 터미널 환경에 완벽하게 통합한 고성능 터미널 에뮬레이터입니다. Rust(Tauri)의 강력한 성능과 React의 현대적인 UI를 결합하여 개발자에게 지능적인 워크플로우를 제공합니다.

핵심 미션

  • AI 기반의 자동 오류 수정 (Self-Healing)
  • 로컬 및 클라우드 AI의 유연한 활용
  • P2P 네트워크를 통한 분산 지능형 협업
  • 시맨틱 검색 기반의 명령 히스토리 관리

기술 스택

Tauri Rust React TypeScript Vite xterm.js libp2p SQLite

2. 주요 기능 상세

🚀 지능형 터미널 (AI-Enhanced Terminal)

xterm.js를 기반으로 구현된 터미널은 PTY(Pseudo Terminal)와 직접 연결되어 표준 쉘 환경을 제공합니다. 여기에 AI 기반의 Ghost Text 자동 완성이 실시간으로 제안됩니다.

Self-Healing Loop (자동 자가 치유)

터미널 명령 실행 중 에러가 발생하면 AI가 이를 즉시 감지하고, 에러 메시지를 분석하여 해결책을 제안하거나 자동으로 수정 명령을 실행할 수 있는 루프를 제공합니다.

📚 RAG (Retrieval-Augmented Generation)

로컬 코드베이스를 인덱싱하여 AI가 프로젝트의 구조와 컨텍스트를 이해한 상태에서 질문에 답하거나 코드를 생성할 수 있도록 지원합니다.

🌐 Swarm & P2P Networking

libp2p를 활용하여 여러 대의 Lum 인스턴스를 연결하고, 지식과 리소스를 공유하는 분산 지능형 환경을 구축합니다.

3. 시스템 아키텍처

Frontend (React)

src/ 경로에 위치하며, 기능별 컴포넌트로 분리되어 있습니다.

  • TerminalPane.tsx: 터미널 렌더링 및 입력 처리
  • HealingPanel.tsx: AI 자가 치유 인터페이스
  • DynamicUIRenderer.tsx: AI가 생성한 UI 동적 렌더링
  • useAIProcessing.ts: AI 로직 통합 Hook

Backend (Rust/Tauri)

src-tauri/src/ 경로에 위치하며, 고성능 처리를 담당합니다.

  • commands/terminal.rs: PTY 관리 및 쉘 연동
  • commands/ai.rs: xLLM 및 Gemini 연동 로직
  • swarm.rs: P2P 네트워크 및 통신 프로토콜
  • sandbox.rs: 보안 및 명령어 검증
